> **Note on this conversion**: the source `.doc` lays its periodic table out as an embedded picture plus a Word table built from many merged/empty cells, not as flowing text. No `pandoc`/LibreOffice was available to convert it properly, so this version was reconstructed from a low-level extraction of the document's raw text runs. Cell boundaries for the element legend below are inferred and may not be 100% exact — verify against the original `.doc` or the linked image if precision matters.
