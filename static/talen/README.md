ISO 639-2 are used as the directory naming convention to avoid treating Yiddish, Erzya and Moksha differently from such larger languages as German or Ukrainian.

ISO 639-2 is the alpha-3 code in Codes for the representation of names of languages - Part 2.

If different codes are used for bibliographic and terminology purposes, it is
the ISO 639-2 code for terminology purposes that is used here.

Examples:

- arm (B) vs. hye (T)
- baq (B) vs. eus (T)
- cze (B) vs. ces (T)
- ger (B) vs. deu (T)

Erzya is myv, Moska is mdf, Yiddish is yid

ISO 639-1 is the alpha-2 code.

For the list of codes, consult https://www.loc.gov/standards/iso639-2/php/code_list.php
