*Règle générale* : les adjectifs terminés par -EL et -ER perdent le « E » dès qu'on les décline :

teuer : *eine teure Ware*
euer : *mit eurem Buch*
sauer : *saure Trauben*
edel : *Möbel aus edlem Holz*
heikel : *ein heikles Problem*
eitel : *eine eitle Frau*

sensibel : *ein sensibles Kind*
plausibel : *eine plausible Erklärung*
noble : *ein nobler Mensch*
rentabel : *ein rentables Unternehmen*
penibel : *ein sehr penibler Mensch*
respektabel : *ein respektabler Erfolg*

*NB 1* : font exception à cette règle : **bitter, mager, heiser, tapfer**

*NB 2* : le comparatif de ces adjectifs suit la même règle :

ce cas est encore plus délicat : **dieser Fall ist noch heikler**

*NB 3* : si le nom se termine par E, celui-ci disparaît :

das Auge : **ein blauäugiges Mädchen**
die Stunde : **eine dreistündige Fahrt**
die Woche : **eine dreiwöchige Urlaubsreise**

*NB 4* : ne pas confondre :

— eine dreistündige Fahrt (un voyage qui dure trois heures)
eine dreistündliche Fahrt (un voyage qui a lieu toutes les trois heures)
— fremdsprachige Bücher (des livres écrits dans une langue étrangère)
fremdsprachliche Bücher (des livres qui parlent des langues étrangères)
