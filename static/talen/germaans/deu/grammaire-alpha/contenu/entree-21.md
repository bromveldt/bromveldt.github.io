L'adverbe (*das Adverb, das Umstandswort*) est invariable et généralement placé près du verbe (*ad verbum*). Il peut indiquer :

a) *Le lieu* (hier, da, dort, links, draußen, nirgends, überall...)
b) *Le temps* (morgen, lange, nie, selten, manchmal...)
c) *La cause* (darum, daher, deshalb...)
d) *La manière* (schnell, gern, langsam, probeweise...)
e) *La négation ou l'affirmation* (ja, nein, jemals, nicht, nichts...)
f) *La quantité ou l'intensié* (genug, ziemlich, viel, wenig...)

*NB 1* : un adjectif peut jouer le rôle d'adverbe :

- **er ist böse** (adj) : il est méchant
- **er handelt böse** (adv) : il agit méchamment

*NB 2* : l'adverbe peut venir d'un nom :

- **abends** : le matin
- **mittwochs** : le mercredi
- **nachts** : la nuit
- **vormittags** : dans la matinée...
