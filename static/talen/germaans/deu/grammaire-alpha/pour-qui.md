Ce recueil s’adresse à tous les élèves des lycées à partir de la Troisième et aux étudiants. Il contient (le tout classé par ordre alphabétique, voir la table des matières) 562 tableaux, soit :

a) 131 plans de grammaire ;

b) 70 prépositions ;

c) environ 50 adjectifs à l’emploi délicat ;

d) environ 50 mots où l’étudiant fait une faute une fois sur deux ;

e) environ 200 verbes à régime différent du français ;

f) les pronoms, adverbes, conjonctions et locutions diverses qui sont source de fautes, soit qu’une autre grammaire n’en parle pas (à droite, dans la mesure où, concernant...), soit qu’elle passe sous silence certains aspects de leur emploi (au milieu de, en bas, là-dedans, jusque...).

Les abréviations utilisées dans le recueil sont les suivantes :

A = accusatif ;

D = datif ;

G = génitif ;

qch = quelque chose ;

qqn = quelqu’un ;

ex = exemple ;

NB = nota bene ;

jdn = **jemanden** (= quelqu’un) ;

jdm = **jemandem** (= à quelqu’un) ;

jds = **jemandes** (= de quelqu’un).
